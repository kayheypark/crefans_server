# 충전 콩 환불·청약철회 조사 (2026-10-29)

상태: 조사 완료, 사업자 정책 결정(2026-10-29), 코드·약관 미반영(실결제 콩 판매 전 구현 필요). 확인일 2026-10-29(law.go.kr 원문 대조). 법률 자문 아님.

## 사업자 결정 (2026-10-29, 클릭 응답)
- 충전 후 7일 이내 미사용분: 전액 청약철회(법정).
- 7일 경과 미사용 충전 콩: 요청 시 10% 공제 후 환불(회사 귀책이면 공제 없음). 사용분·운영자 지급 프로모션콩은 환불 제외.
- 충전 콩 유효기간: 충전일로부터 5년(만료 전 안내 필요, 법적 근거 추가 확인).
- 미결: 전자금융거래법 해당 여부(금융위 질의·전문가 검토), 7일 경과 환불의 법령 근거 원문, 서비스 종료·이용제한 시 잔액 처리.

현재: `src/platform/legal-documents.ts`에는 멤버십 환불(5조)만 있고 콩 환불·청약철회 규칙은 서버·약관·가이드 어디에도 없다. 충전 콩은 출금 불가(`bean-policy.ts`)이며 "출금 불가"와 "환불 불가"는 다른 문제다.

## (A) 원문 확인 의무
- 전자상거래법 제17조 제1항(시행 2026.7.21. 법률 제21312호): 계약서면 수령일(공급이 늦으면 공급일)부터 7일 이내 청약철회.
- 같은 법 제17조 제2항 제5호·제6항 단서: 디지털콘텐츠는 제공 개시 시 철회 제한, 가분적 콘텐츠의 미제공분은 철회 가능. 제한하려면 철회 불가 표시와 시험 사용 등 조치(시행령 제21조의2)가 필요하며, 없으면 제한되지 않음.
- 같은 법 제18조: 철회 시 3영업일 이내 환급(지연이자 연 15%, 시행령 제21조의3), 카드는 결제업자에 청구 정지·취소 요청(제3항, 시행령 제22조), 위약금 청구 금지(제9항).
- 같은 법 제35조: 제17~19조에 반하는 소비자 불리 약정은 무효. 일괄 "콩 환불 불가" 고지는 무효·청약철회 방해 위험.
- 공정위 집행 사례: 2012-05-29 모바일게임사 16곳(https://www.korea.kr/briefing/policyBriefingView.do?newsId=148733921), 2015-03-18 7곳(newsId=156041396). 사용하지 않은 사이버캐시는 7일 이내 청약철회 가능, 환불 불가 고지는 방해 행위로 과태료.
- 콘텐츠산업진흥법 제27조(시행 2026.2.1. 법률 제20750호, 소관 문체부): 표시·시험 이용 조치 의무, 전자상거래법 제17·18조 준용.
- 콘텐츠이용자 보호지침(문체부고시 제2024-16호, 시행 2024.3.14.): 제11조 7일 철회, 제16·17조 해지 시 3영업일 내 환급. 자율 준수 지침.
- 소비자분쟁해결기준 별표2 인터넷콘텐츠업(공정위고시 제2025-14호, 시행 2025.12.18.): 미사용 상태 7일 이내 철회 시 구입가 환급. 합의·권고 기준.

## 불확실(판단 필요)
- 7일 경과 후 미사용 잔액 환불 의무: 법령 명문 규정 미확인. 공정위 2012 브리핑은 "7일 이후 적정 위약금 공제 후 환불"을 언급, 2017 모바일게임 표준약관 개정 보도도 미사용 유료아이템 환급. 표준약관 조문·수수료율 원문 미확보.
- 전자금융거래법 선불전자지급수단(시행 2026.10.2. 법률 제22048호) 제2조 제14호 해당 여부: 후원(대가 없음)이라 비해당 가능성 vs 크리에이터 현금 출금으로 가치 이전 여지. 금융위 해석 사례 미확인. 해당 시 제28조 제3항 등록 면제 요건, 제19조 잔액 환급 적용 여부 미확인. 금융위 질의·전문가 검토 권장.

## 업계 관행(법 아님)
- SOOP 별풍선: 선물하지 않은 별풍선은 7일 이내 청약철회(https://item.sooplive.com/starballoon.php). 유료서비스 이용약관 제19조: 잔여 캐시 요청 시 3영업일 내 결제수단 환불, 사용분·무상 지급분 제외, 회원 귀책 아닌 경우 수수료 면제(https://www.sooplive.com/policy/policy1_u_info.html).
- 치지직 치즈·트위치 Bits: 공식 페이지 미확인.

## (B) 기술 권장안
- 충전 건(Toss paymentKey)별 충전 시각·충전 콩·사용 콩 추적으로 미사용분 계산. 현재 차감 순서는 프로모션콩 → 충전콩(`bean-policy.ts` consumptionOrder).
- 철회는 Toss 부분취소로 원결제수단 3영업일 내 환급. 충전 화면·약관에 철회 기간·조건 고지, 일괄 "환불 불가" 금지. 반복 남용 제한 조항.

## (C) 사업자 결정 사항
- 7일 경과 후 미사용 잔액 처리(환불 불가 / 수수료 공제 후 환불 / 무수수료 환불), 수수료율, 유효기간, 회사 귀책·서비스 종료 시 처리, 탈퇴 시 잔액, 이용제한 회원 잔액, 과오충전 기준.
- 7일 내 미사용분 전액 철회, 일부 사용 결제의 미사용분만 철회, 프로모션콩 환불 제외는 세 선택지 공통.
