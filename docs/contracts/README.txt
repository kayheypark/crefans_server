크레팬스 크리에이터 계약서 인수인계
갱신: 2026-10-31(v2.35) / 상태: 사용자 초안 승인,法務 최종 검토·서명 전

1. 현재 상태
사용자는 계약 초안 내용과 공식 계약서 형태의 흑백 A4 서식을 수용했다.
최신 PDF는 output/pdf/crefans-creator-agreement-draft.pdf (현재 7쪽).
정부 승인 표준계약서 또는 법률 자문 완료 문서가 아니다.
계약 체결·사이트 배포·약관 적용은 별도 요청 없이 실행하지 않는다.

2. 수정 파일 지도
- crefans-creator-agreement-draft-20261030.txt: 계약 본문 원본. 13조, 별지 A/B, 서명.
- creator-agreement-research-20261030.txt: 최초 공식 조사·미확정 조건. 당시 조사 범위 기록이므로 소급해 덮어쓰지 않는다.
- layout/contract.css: A4 여백22mm, 본문11pt, 항 들여쓰기, 당사자/조건/서명 표 서식.
- layout/parties.html: 첫 페이지 당사자 기입 표. 원본 TXT 회사 정보와 대조한다.
- build-contract-html.py: TXT를 파싱해 조문·별지 렌더. 표제/안내/서명 표 문구도 이 파일에 있으므로 해당 문구 수정 시 TXT와 양쪽 대조한다.
- build-contract-pdf.cjs: Chromium으로 PDF 생성. 문서 내용은 수정하지 않는다.
- verify-contract-pdf.py: 13조·별지 A(별지 B 없음)·서명 제목과 페이지 경계 검사 및 전 페이지 PNG 출력.
- contract-pdf-layout-20261031.json: 승인 당시 PDF 해시와 서식 참고 근거. 다음 수정 시 이전 증거를 완료 증거로 재사용하지 않는다.
- output/pdf/crefans-creator-agreement-draft.pdf: 전달용 생성물. 직접 수정하지 않는다.
- tmp/pdfs/: 생성 HTML/PNG/검사 결과. 이 임시 폴더 없이도 위 영구 소스로 재생성 가능.

3. 재생성 (crefans_server 루트)
python3 docs/contracts/build-contract-html.py
node docs/contracts/build-contract-pdf.cjs
python3 docs/contracts/verify-contract-pdf.py

의존성: Python3, Node, 형제 crefans_front의 playwright와 Chromium.
검사용 Python에 pymupdf 설치 필요. 현재는 다음 전용 환경 사용 가능:
.local/contract-pdf-venv/bin/python docs/contracts/verify-contract-pdf.py
새 컴퓨터: python3 -m venv .local/contract-pdf-venv
.local/contract-pdf-venv/bin/pip install pymupdf
Node 버전은 각 저장소 .nvmrc에 맞춘다.
폰트 기본 경로는 형제 crefans_guide/public/fonts/Pretendard-Regular.subset.woff2.
다른 위치는 CREFANS_CONTRACT_FONT 환경변수로 지정. 폰트 파일을 임의 재배포하지 않는다.

4. 검수 기준
- TXT 13조와 별지 문구가 PDF에 빠지지 않았는지 확인한다.
- 제목·회사정보·계약일·개별조건·서명은 별도 서식 처리이므로 원본과 직접 대조한다.
- 검증 PNG를 전부 열어 한글 누락·겹침·표 잘림·빈 페이지·제목 고립 확인.
- 페이지 수는 내용에 따라 달라질 수 있다. 7쪽을 맞추기 위해 글자를 무리하게 축소하지 않는다.
- 자동 검사는 텍스트 경계와 제목만 확인한다. 실제 의미·본문 전부 보존·법률 적합성을 자동 보장하지 않는다.
- 출력 후 해시·변경요약·검사 결과·미검증 항목과 PROGRESS.md 갱신.
- 프론트에서 npm run docs:record 및 npm run check:docs 실행. 새 문서는 docs/audit/manifest.json에 검토근거와 함께 등록.
